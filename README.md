# СПАРК · S.P.A.R.K. — версия 13

Готовый статический сайт. Для просмотра распакуйте архив и откройте index.html.

## Правки версии 13
- Порядок разделов: спикеры, затем программа.
- Новая ссылка на оплату во всех кнопках: https://payform.ru/jgcR5wn/.
- Темы всех девяти выступлений добавлены в программу и карточки спикеров, биографии сохранены полностью.
- В разделе партнёров добавлены три предоставленных логотипа.

## Правки версии 12
- Добавлен раздел «Партнёры» перед заключительным экраном: Компания Телебосс — онлайн-конференции, магазин иностранной литературы Anybooks, Школа Татьяны Фанштейн.

## Правки версии 11
- В версии 11 программа была расположена перед спикерами; в версии 13 по новому запросу возвращена после спикеров.
- Удалён раздел «03 · Зачем приходить».
- Оба пункта о партнёрах названы «Информация о партнёрах».
- Все названия пунктов программы набраны одинаковым шрифтом и размером.
- Цена указана только в блоке билетов.

## Что изменено
- Цветная объёмная карусель девяти спикеров с полными исходными биографиями.
- Выбор фото, кнопки имён, стрелки, перетаскивание мышью и свайп. Клавиши ← / →, Home / End работают, когда карусель в фокусе.
- Порядок спикеров в карусели соответствует расписанию. Автопрокрутка отключена для спокойного чтения.
- Отдельная программа: 16 интервалов с 9:30 до 17:30. Имя в программе выбирает соответствующего спикера.
- Стоимость билета — 6000 ₽. Все кнопки оплаты: https://payform.ru/jgcR5wn/.
- Удалены формулировки о ранней цене. Остальные исходные тексты сохранены, кроме удалённого по запросу раздела «Зачем приходить».
- Адаптивная вёрстка и поддержка reduced motion. Без JavaScript биографии остаются обычным полным списком.

## Размещение
Загрузите содержимое этой папки в корень репозитория сайта, заменив прежние файлы. Сохраните папку assets рядом с index.html. Для GitHub Pages выберите ветку main и / (root) в Settings → Pages. Сборка и установка пакетов не требуются.
