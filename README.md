# СПАРК — версия 14

Добавлена форма перед оплатой: email, ФИО, телефон и три отдельных, изначально пустых флажка. Оферта и обработка данных обязательны; согласие на распространение необязательно для покупки. Все четыре документа доступны в подвале сайта и форме, в HTML и исходном DOCX. Оригинальный текст документов сохранён.

Сохранены карусель и полные биографии, темы выступлений, программа после спикеров, логотипы партнёров и стоимость 6000 ₽ в блоке билетов.

## Подключение и размещение

Обработчик Apps Script опубликован; URL указан в checkout-config.js. В указанной закрытой Google Таблице создан лист «Заявки СПАРК». В браузере проверены запись вымышленной заявки и повтор без дубля. Тестовая строка явно помечена «ТЕСТ ИНТЕГРАЦИИ — НЕ УЧАСТНИК» и не означает реальное согласие или покупку.

Для обновления действующего сайта загрузите содержимое этой папки в корень репозитория, сохранив assets и legal. Файлы integration публиковать необязательно. Живой сайт в этом сеансе не обновлялся. Обработчик принимает источник https://spark-conference.github.io/spark2/; при смене адреса обновите проверку в Code.gs и разверните новую версию. На localhost сохранение обычной формы намеренно отклоняется; живая проверка проводилась отдельным тестовым стендом с явно обозначенным тестовым источником.

После подтверждения записи форма открывает https://payform.ru/jgcR5wn/. Проверено: ссылка ведёт к билету стоимостью 6000 ₽. Контакты через POST эта платёжная ссылка не подставляет, поэтому на Prodamus их нужно ввести повторно; об этом сказано в форме. Контактные данные не добавляются в URL.

В кабинете Prodamus нужно исправить название товара: сейчас там «Билет на конференцию СПАРК 2027 (ранняя цена)». Страница оплаты и её документы в кабинете Prodamus не редактировались. Четыре предоставленных документа размещены в файлах сайта и связаны с формой до оплаты. Реальная оплата не выполнялась.

## Учёт заявок

Сохраняются контактные данные, отдельные согласия, серверное время, версии и контрольные суммы документов, тексты подтверждений, клиентские отметки времени и ID заявки. Повтор той же заявки не создаёт дубль. Ошибка сохранения останавливает переход к оплате. Статус «заявка сохранена» не подтверждает оплату: обратное уведомление Prodamus не подключено.

Apps Script не предоставляет IP посетителя — в журнале это указано явно. Если нужен IP, требуется другой серверный обработчик. В оферте окончание мероприятия указано в 18:00, а в программе — в 17:30; документы не исправлялись. Техническая реализация не заменяет проверку документов и порядка обработки данных организатором.

## Проверки

Пройдены локальные проверки серверной логики с имитацией Google Sheets и формы с имитацией ответа: обязательные поля и согласия, повторы, конфликты ID, ошибки записи и сети, запрет перехода без подтверждения. Проверено открытие формы на сайте. Живая запись и идемпотентный повтор проверены из браузера, страница Prodamus открывается с суммой 6000 ₽. После загрузки на GitHub Pages рекомендуется проверить полный путь с опубликованной страницы.
